# Olist Data Warehouse

## Project Overview

This project implements a modern Data Warehouse in PostgreSQL using the Medallion Architecture.

### Architecture

Bronze Layer
- Raw ingestion from CSV files

Silver Layer
- Data cleansing
- Standardization
- Validation

Gold Layer
- Dimensional modeling
- Analytics-ready datasets

### Technology Stack

- PostgreSQL
- SQL
- DBeaver
- Git/GitHub

### Dataset

Brazilian E-Commerce Public Dataset by Olist
